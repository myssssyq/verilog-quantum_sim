# Changelog

## 0.2.0

- added phase gates: `S`, `SDG`, `T`, `TDG`
- updated the HDL to handle the new instructions
- added a Python reference simulator
- added a UART host utility
- added a small host-side compiler for selected gate decomposition
- added tests for the compiler
- expanded the testbench
- cleaned up the README and documented the current limits
- added MIT license
- added photo verifications

## 0.1.0

- built the first working 3-qubit simulator for Tang Nano 9K
- added the base instruction set and assembler
- added sample programs and Verilog simulation support
